How the checks work

Relative vs absolute IC50

The relative IC50 is the inflection point of the fitted curve (halfway between its top and bottom plateaus). The absolute IC50 is the concentration where the curve crosses 50 % viability. They are the same only when the curve runs from 100 % to 0 %. With partial inhibition they differ, and your paper should say which one is reported.

When is an IC50 not reportable?

If the curve never drops below 50 %, there is no IC50 inside the tested range; report it as "> highest concentration". If the IC50 falls outside the tested range, it is an extrapolation and should be confirmed with a wider concentration series.

Confidence interval

The 95 % CI is computed on log IC50 from the fit's covariance matrix with the t-distribution, then back-transformed. A CI wider than 10-fold means the data do not pin down the IC50.

Outliers

Points more than 3 residual SDs from the curve are marked in red. They are not removed automatically – check the well first.

Model

y = Bottom + (Top − Bottom) / (1 + 10(log C − log IC50) × Hill), fitted by bounded Levenberg–Marquardt least squares on all replicate points. Results were checked against SciPy curve_fit.
